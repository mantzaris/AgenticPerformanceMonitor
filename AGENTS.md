# Repository instructions

## Git workflow

- Work on `main` and commit completed changes directly to `main`.
- Push completed commits to `origin main`; the repository owner has requested this workflow.
- Create a separate branch only when the user explicitly requests one.
- Preserve existing history and unrelated work. Do not force-push.
- If authentication or another blocker prevents pushing, leave the local commits on `main` and report the blocker.
