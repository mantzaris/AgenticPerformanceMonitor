# Final-validation preparation — blocked, not an execution protocol approval

No agent condition met the Stage 6 gate. Enumeration met it, but that does not
promote an agent or establish a novel unrestricted analytical system. **Do not open
reserved observations or launch final validation from this document.** No final
agent candidate is selected. The immediate recommendation is external review and
a separately versioned scoring audit using existing artifacts, with zero new
model generations and no reserved data. Human review remains pending.

This conditional design records what would have to be locked if a later, separately
reviewed decision justifies final validation. It is not a new experiment, a promise
to tune until passing, or authorization to broaden the project.

1. Resolve the recent-mean/personal-claim equivalence issue, the treatment of
   separately displayed personal windows, unavailable-mean answer forms, and
   scientific support thresholds. Two reviewers (domain/statistics and
   visualization/evaluation) should independently judge questions and displayed
   answers, then record adjudication. Automated source checks remain separate.
   Preserve the Stage 6 scores; any post-hoc reanalysis gets its own version.
2. Preregister one fixed system and its exact scope. Enumeration can be audited as
   the operational registry system. An agent candidate requires a new external
   decision with a concrete rationale; none currently qualifies. Freeze the
   scorer after human review, prompts, code, model/runtime and failure policy
   before opening any evaluation observations. Do not choose a best method per case.
3. Use the existing unopened person-level reserved split only after authorization.
   A proposed balanced sample is 120 distinct people, 20 per established family,
   selected by a new preregistered hash seed using only structural eligibility.
   Group all registrations by person; preserve the fixed development reference
   pool excluding all 81 prior focal people. Do not use outcome magnitudes or
   method performance. A custodian should record shortages and any relaxation
   before inference. Reserved observations have not been read for this proposal.
4. Prespecify complete valid visible answers and method-selected completeness,
   numerical integrity, separately scoped insufficiency, unavailable measurements,
   missing analyses/omissions, and cost. Include every attempted or blocked slot.
   No fallback counts as agent success; no reruns until passing. Report calibrated
   human agreement and disagreements, not automated review as independent review.
5. Necessary controls depend on the fixed claim: enumeration is mandatory for an
   agent study; unchanged A is the agent control. A claim specifically about
   explicit identity also requires B, rather than only C versus A. Do not drop
   an unfavorable control. Counterbalance condition order and retain equal budgets.
6. Use person/case as the paired unit. If paraphrases or registrations are added,
   cluster all of them by person. Resample people within family, carrying every
   paired condition together, and retain the prespecified equal-family weighting.
   Report counts and person-bootstrap 95% intervals for paired completeness
   differences, plus per-family descriptive results and
   appropriate binomial intervals for absolute integrity/completeness. With only two course presentations, do not claim generalization to new courses.
   These evaluation intervals are distinct from dashboard peer-mean bootstrap intervals.
   Prespecify a single primary contrast; avoid cherry-picked family significance.
7. A conservative ceiling for a future 120-case, three-agent-plus-enumeration
   design is 360 agent episodes, 1,440 comparison generations plus at most 32 setup
   generations, six tools/four generations/one repair each, one 14B BF16 GPU load,
   four model-process hours and six elapsed execution hours. Stage 6 used about
   21.2 episode seconds per agent case; linear extrapolation is about 2.1 hours for
   360 episodes plus loading, with substantial margin for length/failure variation.
   This is a compute estimate, not a billing estimate or authorized budget. A
   baseline-only operational audit needs no model process; a two-agent design
   requires at most 960 comparison generations. Stop and preserve incomplete
   conditions if the separately approved future ceiling is reached.
