# External scientific review items

These notes index limitations of the frozen design; they do not change any pilot
requirement, prompt, policy, scoring code or source observation.

1. Approve each question-level required answer and its admissible visual forms.
   In particular, decide when a focal/reference bar chart is sufficiently explicit
   without a separate numeric sentence. The current frozen rule permits it when
   source support and window/reference bindings are valid.
2. Review genuinely scoped insufficiency separately from the true but existential
   global conclusion. A unique unsupported referent can be resolved globally;
   multiple unsupported comparisons need their own attribution. Check that this
   rule matches what a reader can determine from the visible dashboard.
3. Judge paired-phrasing equivalence and realism. Shared facts, cutoffs and scoring
   contracts are mechanically identical; this is not independent human confirmation
   that the language is equivalent. Historical Stage 2 activity wording remains
   underspecified, so its post-hoc reanalysis is provisional rather than definitive.
4. Decide whether compiler-supplied grade/learning caveats count toward overall
   answer completeness. Both total-visible and method-selected endpoints are
   reported. Standard context is not evidence of an agent selecting an analysis.
5. The new policy bundles a public task map with phase reminders; this design
   cannot isolate their individual effects. The old policies have unchanged policy
   texts but run under a shared Stage 3 schema/public-rule interface. This is not an
   exact Stage 2 replication.
6. Agent episodes share an integrity cache within their process. Counterbalanced
   order avoids assigning every first position to one method, but episode latency
   is not an isolated cold-cache benchmark. Shared load and profiling overhead are
   separate, and recorded CUDA-event durations are not pod billing duration.
7. Twelve development people with paired phrasings do not establish repeatability,
   generalization, educational utility, or superiority on new task families. The
   small fixed registry is favorable to a strong enumeration baseline. Any broader
   advantage of flexible agent investigation remains an untested hypothesis.
8. Retain the Stage 2 statistical limitations: administrative rather than actual
   exposure, unknown logging completeness and grading/banking release times,
   changing peer composition, unequal observed histories, and provisional support
   thresholds. No mixed-model artifact is used as a validated detector or source
   of dashboard claims.
